# V16.3 — تقرير استبدال مصدر الصور

## استبدال المصدر V16.3

- استبدال مسار Pexels بـPixabay بسبب توقف إصدار مفاتيح جديدة كما في صورة المستخدم؛ النسخة تحتاج PIXABAY_API_KEY بدل PEXELS_API_KEY.
- ربط مخطط API الفعلي: hits وtags وuser وpageURL وlargeImageURL وأبعاد الأصل، مع فحص النوع photo والوسوم والروابط، ثم فحص أبعاد الملف المحمل.
- إبقاء ستايل الشباب ومعالجة الأبيض والأسود والليل، مع دعم وسوم الملابس واللون المنفصلة دون اختراع أوصاف من عبارة البحث.
- تخزين ردود البحث الناجحة 24 ساعة دون مفاتيح بنص واضح، وتنقيح الأخطاء التي قد تتضمن عنوان الطلب. أخطاء API لا تُخزن كنجاح.
- تحديث اختبارات المصادر والتلقائي لتستخدم مخطط Pixabay، مع فحوص مستقلة للمفتاح والذاكرة المؤقتة.
- محاولة قراءة توثيق Pixabay الحي أعادها وكيل الشبكة برفض 403. إتاحة إصدار مفتاح جديد وعملية جلب الصور الحية لم تُختبرا؛ تعليمات الحساب تخضع للموقع.

## إصلاحات التلقائي V16.2

- فصل مهلة الجلب الخلفي عن الجلب عند حاجة الروم، ليتمكن نشر 40 دقيقة من طلب طقم جديد رغم مهلة الخلفية البالغة 80 دقيقة.
- تسجيل نجاح/فراغ/فشل الجلب وسبب الخطأ ووقت إعادة المحاولة. فشل المفتاح أو الشبكة لا يسبب مهلة نجاح 80 دقيقة، وتظهر الأخطاء في حالة البوت والروم.
- توحيد الطلبات الجارية للقسم نفسه وانتظارها عند النشر، ومنع تداخل دورات المؤقتات. جدولة النشر تبدأ بعد استعادة سجل الرسائل.
- قصر الجلب الخلفي على مصادر الأطقم، ومنع طلب Wallhaven مرتين عند نفاد الصور. تسلسل بحثه وإرساله على مستوى السيرفر يمنع اختيار نفس الصورة في طلبين متوازيين.
- فحص Embed Links قبل جلب المصادر، وعدم احتساب النشر عند رفض الإرسال. إصلاح تراكب خط إطار البانر على الأفتار في محرك الرسم.
- تشغيل `npm start` أكد توقف الدخول بسبب عدم وجود DISCORD_TOKEN. فحص وجود الإعدادات أكد عدم وجود .env وPIXABAY_API_KEY وFANART_API_KEY. لم تُطبع قيم أي أسرار.
- طلب Wallhaven العام عبر HTTPS رفضه وكيل الشبكة أثناء إنشاء النفق (403 Forbidden)؛ هذا ليس رد API من Wallhaven، ولا دليلًا على تعطل الموقع.
- اختبار المؤقتات يسجل أوقات البدء الفعلية ويستدعي ردودها مع تقدم الزمن بدل الانتظار. يغطي تلقائيًا الأقسام الخمسة، الروم المتوقف/غير المستحق، نشرًا جديدًا بعد 40 دقيقة، نقص المفتاح ثم إعادة المحاولة، فشل الإرسال، الصلاحيات، التداخل، والجلب الخلفي. المصادر وDiscord محاكاة؛ لا إرسال خارجي.

## ستايل الشباب V16.1

- تعديل بحث قسم boys فقط لصور هوديز وملابس شارع داكنة وزوايا خلفية أو جانبية، وبنرات حضرية أو طبيعة غائمة أو ليل.
- ترتيب المرشحين حسب وصف الستايل ورفض صور البورتريه العام والعمل الرسمي.
- توحيد ألوان الأفتار والبنر بالأبيض والأسود أو معالجة ليلية باردة مع فحص السطوع؛ فحص جودة وتكرار الطقم يستمر قبل الحفظ.
- استبعاد أطقم الشباب القديمة المرفقة/المجلوبة تلقائيًا دون حذفها، مع إبقاء صور المشرفين المراجعة. لا صور إنترنت جديدة مرفقة.
- لا تغيير لمصادر البنات والأنمي وPC والأفلام أو تصميم البطاقة.

## التغيير

- حذف وحدات Openverse وWikimedia Commons وTMDB وكتالوج أفلام Commons القديم من النسخة التنفيذية.
- البنات والشباب: Pixabay عبر API رسمي، مع فلاتر وصف وأبعاد وصور فوتوغرافية وألوان، وفحص الأفتار والبنر قبل الحفظ.
- الأنمي وخلفيات PC: Wallhaven عبر API الرسمي، مع SFW ومعاينات وروابط المصدر، دون إدخالها كأطقم مركبة تلقائيًا.
- الأفلام: Fanart.tv، باختيار ملصق وخلفية من نفس معرف فيلم IMDb. لم يعد هناك فلتر Netflix.
- الإبقاء على الأقسام الخمسة وأوامر الإدارة والفواصل والمكتبة المحلية، وإظهار المصادر الجديدة في /مصادر والقائمة وحالة البوت.
- استبعاد السجلات القديمة للمصادر المحذوفة من النشر مع إبقاء ملفاتها وبياناتها محفوظة. لا يحذف التحديث المنشورات السابقة من ديسكورد.
- تحديث .env.example وتعليمات الاستضافة والمصادر؛ نقل تقارير V14/V15 التاريخية إلى docs/history.

## ما تم التحقق منه

- تثبيت الحزم بنجاح باستخدام Node.js 24.19.0 وnpm 11.9.0.
- نجاح `npm run check` لجميع ملفات JavaScript التنفيذية.
- نجاح `npm test`: 14 مجموعة اختبار.
- اختبار ستايل الشباب: ترتيب أوصاف الهوديز والزوايا الخلفية/الجانبية، استبعاد البورتريه العام والصور الرسمية، التحقق من بكسلات أبيض وأسود وألوان ليلية فعلية، ورفض صور الليل الساطعة، والحفاظ على أبعاد المصدر. اختبارات التخزين تؤكد استمرار نشر صور المشرف المراجعة وقابلية تكرار ترحيل الستايل دون تصفير مهلة الجلب مجددًا.
- اختبار المصادر: توجيه الأقسام الخمسة، طلبات API ومفاتيحها في الترويسات، HTTPS ومضيفو الصور، منع الأقسام الخاطئة والصور المتكررة والنتائج الناقصة، أخطاء التفويض وحد الطلبات، وتجاوز فيلم بلا صور (404).
- اختبار التكامل المعزول: جلب صور محاكاة لكل قسم، حفظ أطقم Pixabay/Fanart.tv ومعالجتها فعليًا بـsharp، اختيارها للنشر، بناء بطاقة Discord مع النسب للمصدر، وبناء معاينات Wallhaven وحفظ سجل النشر. لا يُرسل الاختبار أي رسالة إلى Discord.
- استمرار نجاح الاختبارات السابقة للتصنيفات الخمسة، استقلال الرومات، ترحيل الإعدادات، سجل النشر، منع تكرار المكتبة، وعرض جميع الصور المحلية المرفقة.

## ما لم يتم التحقق منه

لا توجد مفاتيح Pixabay/Fanart.tv أو توكن Discord متاحة لهذه النسخة؛ لذلك لم يُنفذ تسجيل الدخول إلى Discord أو جلب صور حية من المصادر الجديدة. اختبارات API محاكاة وليست دليل وصول من Bot-Hosting أو دليل صلاحية مفتاح المستخدم. يلزم إدخال PIXABAY_API_KEY وFANART_API_KEY وDISCORD_TOKEN في بيئة الاستضافة، ثم تجربة /جلب-صور و/نشر-الآن لكل قسم.

الملف المضغوط لا يحتوي على node_modules أو .env أو storage أو بيانات دخول. المكتبة المحلية والصور الأصلية المرفقة لم تُستبدل ولم يُدّعَ أنها صور جُلبت من المصادر الجديدة.
