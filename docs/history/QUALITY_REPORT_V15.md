# تقرير فحص ABO 7RB V15

## ما تم تنفيذه
- Wallhaven API v1، بحث آمن SFW بلا مفتاح إلزامي، ودقة PC لا تقل عن 1920×1080، والتصنيف General فقط.
- عرض رابط ومعاينة خلفية PC بدل تنزيل غير المرخّص، وعدم تكرار معرّف الخلفية على مستوى رومات السيرفر.
- مصدر احتياطي للـPC من صور Openverse/Wikimedia المرخّصة عند الفشل.
- أمر `/استكشاف-وولهيفن` وقائمة عربية، دون خلط الصور الخارجية مع أطقم الأفتار والبنر.
- بقيت تصنيفات anime/movies/girls/boys/pc_wallpapers والجدولة 40 دقيقة والحذف للمشرف فقط.

## الاختبارات
- `npm run check`: ناجح لجميع الملفات.
- `npm test`: نجحت 11 مجموعة اختبارات بعد توفير sharp من البيئة المحلية للاختبار؛ شملت تصنيف الصور، منع التكرار، جودة الصور، المصادر، روابط Wallhaven، وأبعاد الصور.
- فحص zip: التأكد من ملفات التشغيل والاختبارات والصور والشرح وعدم إدخال .env والتوكنات.

## لم يتم اختباره حيًا
- اتصال Wallhaven الفعلي من Bot-Hosting؛ اختبار API عبر استجابات محاكاة فقط.
- تسجيل دخول Discord وتشغيل الرسائل على استضافتك.
- تثبيت npm لم ينجح بسبب فشل DNS للاتصال بـregistry.npmjs.org؛ الحزم مدرجة في `package.json` للتثبيت على استضافتك.
- لا نضمن أن كل رابط يتيح معاينة تلقائية من Discord؛ يوجد رابط مباشر لصفحة المصدر دائمًا.

## قيد مهم
صور Wallhaven ليست تلقائيًا مرخّصة لإعادة الرفع أو الاشتقاق. لذلك لا يتم حفظها كأفتار أو بنر جديد من ذلك المصدر، بل روابط صفحات ومعاينات فقط. لا يوجد وعد بمحتوى لا نهائي أو بتصنيف بصري مضمون 100%.
