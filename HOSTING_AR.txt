ABO 7RB — نسخة الاستضافة V16.13

خطأ الرفع الظاهر في الصورة:
Cannot reach the node from your network (blocked host or port)
يعني أن المتصفح لم يتمكن من الاتصال بخادم الملفات. هذا يحدث قبل تشغيل كود البوت، ولا يثبت وجود خطأ في الكود. تغيير ملف ZIP وحده لا يعالج حظر الاتصال بالخادم.

لإكمال الرفع:
1. جرّب فتح لوحة الاستضافة من شبكة أخرى، مثل بيانات الجوال، ثم أعد الرفع.
2. إذا استمر الخطأ، افتح Settings في لوحة السيرفر وابحث عن SFTP Details.
   استخدم WinSCP أو FileZilla، واختر SFTP وأدخل العنوان والمنفذ واسم المستخدم كما تظهر في اللوحة. لا تفترض أن المنفذ22.
3. فك الضغط على جهازك وارفع محتويات الحزمة إلى مجلد تشغيل السيرفر عبر SFTP.
4. إذا فشل SFTP أيضًا، أرسل نص خطأ Cannot reach the node لدعم الاستضافة واطلب فحص عنوان ومنفذ خادم الملفات وحالة الـNode.

تركيب هذه الحزمة:
- توجد index.js وpackage.json مباشرة في جذر ZIP، دون مجلد خارجي.
- لا ترفع ZIP داخل مجلد آخر وتترك الملفات داخله دون فك الضغط.
- عند تحديث نسخة موجودة، احتفظ بملف .env ومجلد storage الخاصين بك.
- احذف مجلد assets وexamples القديمين إذا بقيا من نسخة سابقة؛ لم يعد البوت يستخدمهما.
- استخدم Node.js 22.12 أو أحدث (يمكن اختيار24).
- انسخ .env.example باسم .env وأدخل مفاتيحك، أو احتفظ بملفك الموجود. لا توجد مفاتيح حقيقية في هذه الحزمة العامة.
- ثبّت الاعتماديات: npm ci --omit=dev
- ملف التشغيل: index.js
- أمر التشغيل: npm start
- داخل Discord استخدم /تجهيز-الرومات أو /ربط-روم، ثم /نشر-الآن.
- إذا رفع الملف وبدأ التشغيل ثم توقف، راجع Console؛ هذا خطأ مختلف عن فشل الرفع، ويُشخّص بنص سجل التشغيل دون مشاركة التوكن والمفاتيح.

تحديث V16.10: ارفع الملفات الجديدة فوق ملفات البرنامج ثم أعد التشغيل. احتفظ بـ.env وstorage. الرسائل الجديدة بلا وصف، وتحميل الأنمي والأفلام ملف PNG واحد. يظهر اعتماد Unsplash عند SHOW_IMAGE_CREDITS=true، وهو مطلوب وفق إرشادات API الخاصة بهم.

تحديث V16.11: ارفع مجلد src كاملًا بما فيه button-icons.js ثم أعد التشغيل. يجهز البوت أيقونات الأزرار الرمادية تلقائيًا؛ تظهر في المنشورات الجديدة. احتفظ بـ.env وstorage.

تحديث V16.12: إصلاح movies. ارفع ملفات البرنامج الجديدة مع الاحتفاظ بـ.env وstorage ثم أعد التشغيل. جرّب /نشر-الآن واختر روم movies. لا يحسب البوت الطقم منشورًا بمجرد الجلب أو المعاينة، ويعيد تنزيل الصور من المصدر قبل إرسالها. /حالة يوضح نقص ربط الروم أو آخر خطأ للمصدر.

تحديث V16.13: الشباب والبنات يستخدمان بطاقة الأنمي نفسها افتراضيًا، بما فيها المعاينة والتحميل. ارفع ملفات البرنامج الجديدة ثم أعد التشغيل، مع الاحتفاظ بـ.env وstorage. الإعداد PHOTO_DISPLAY=card هو الافتراضي حتى إذا لم يكن السطر موجودًا في .env القديم. اسمح بصلاحية Attach Files وباتصال الاستضافة بـimages.unsplash.com.

متطلبات Unsplash API تشمل الربط المباشر والنسبة للمصورين؛ قالب البطاقة لا يحقق شرط الربط المباشر. خيار PHOTO_DISPLAY=source مع SHOW_IMAGE_CREDITS=true يبقي عرض المصدر ونسبته.
